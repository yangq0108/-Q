# 셀프등기 도우미

부동산 셀프등기(매매·근저당권 말소·전세권설정·증여·상속) 절차를 상황별 질문에 따라
맞춤 체크리스트로 안내하는 정적 웹페이지입니다.

## 사용 방법

`index.html` 파일을 더블클릭하거나 브라우저로 열면 바로 실행됩니다.
별도의 설치·빌드·서버 구동이 필요 없는 순수 HTML/CSS/JavaScript 단일 파일입니다.

- 외부 의존성 없음 (npm, node_modules 없음)
- 답변·체크리스트 상태는 브라우저의 `localStorage`에 저장되어, 다시 열어도 이어서 볼 수 있습니다.
- 점(`.`)으로 시작하는 파일/폴더가 전혀 없어서, 이를 지원하지 않는 드라이브(클라우드 가상 드라이브 등)에서도 폴더째로 복사해 사용할 수 있습니다.

## 파일 구성

- `index.html` — 전체 애플리케이션 (데이터, 로직, 스타일 포함)
- `DESIGN.md` — 색상·타이포그래피·컴포넌트 등 디자인 시스템 정의 ([DESIGN.md 포맷](https://github.com/google-labs-code/design.md) 기반)

## 배포 및 접근 제한

GitHub Pages로 배포되어 있으며, 첫 화면에 간단한 공유 비밀번호 입력 화면이 뜬다.
비밀번호는 `index.html`의 `GATE_PASSWORD` 상수에 평문으로 들어있고, 한 번 맞으면
그 브라우저의 `localStorage`에 기억되어 다음 방문부터는 다시 묻지 않는다.

이 잠금은 **검색엔진 노출을 피하고 링크를 아는 사람만 들어오게 하는 용도**일 뿐,
저장소가 공개(public)이므로 페이지 소스를 보면 누구나 비밀번호를 확인할 수 있는
수준의 가벼운 보호다. 실제로 민감한 개인정보를 담지 않도록 유의할 것.
비밀번호를 바꾸려면 `GATE_PASSWORD` 값을 수정한 뒤 다시 업로드/배포하면 된다.

이 페이지의 안내는 일반적인 절차를 요약한 참고 자료이며, 법률·세무 자문을 대체하지 않습니다.
